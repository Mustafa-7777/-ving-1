# My CV Website

This project is a personal CV website created as part of a web development project.

## Technologies

- HTML
- CSS
- JavaScript

## Getting Started

To open the website locally:

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

You can also use **Live Server** in VS Code.

```text
Open index.html → Open with Live Server
```
